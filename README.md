# PowerCMS 12 · Common

PowerCMS Community Edition shared kernel: unified error model, domain events and common value objects.
It does not depend on Spring Web.

This repository contains **Community Edition code only**. Professional, Enterprise and Xinchuang
capabilities live in separate, proprietary modules and are not part of this repository.

## Requirements

- JDK 21
- Maven 3.9+

## Build

```bash
mvn clean install
```
